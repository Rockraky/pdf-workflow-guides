# PDF Workflow Guides

Practical guides for everyday PDF tasks, with tips for protecting your files and checking your results.

## Merge PDF Files
1. Arrange your PDF files in the required order.
2. Check page sizes and orientation.
3. Combine the files using a PDF merger.
4. Review the final page order before sharing.

## Split a PDF
1. Identify the pages or page ranges you need.
2. Choose whether to extract selected pages or create separate files.
3. Save the output with descriptive filenames.
4. Check that every required page is included.

## Create an N-Up PDF
N-up layouts place multiple PDF pages on one sheet.

1. Choose a layout such as 2, 4, 6, or 9 pages per sheet.
2. Select the sheet size and orientation.
3. Check page order, margins, and text readability.
4. Preview the result before printing.
5. When printing an already generated N-up PDF, use one page per sheet to avoid applying the layout twice.

## Convert Images to PDF
1. Arrange your images in the correct order.
2. Rotate images where necessary.
3. Choose a suitable page size and margins.
4. Generate the PDF and check image quality.

## Convert PDF Pages to JPG
1. Select the pages you want to convert.
2. Choose an image quality suitable for your needs.
3. Convert and check that small text remains readable.

JPG files do not preserve selectable text, links, or interactive form fields.

## Privacy and File Handling
- Check whether a tool uploads files or processes them locally.
- Follow your workplace rules when handling confidential documents.
- Keep a backup of the original file.
- Large files may exceed your device's available memory. Try smaller batches if processing fails.
